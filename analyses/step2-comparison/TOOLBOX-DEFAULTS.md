| Tool | What the default permutation does (source) | Step 1 analogue | Shared-block result (step 1, label-fitted decoders) |
|---|---|---|---|
| scikit-learn `permutation_test_score` (MNE-Python decoding relies on it); default `cv=None` = 5-fold StratifiedKFold **without shuffling** (contiguous folds in time order) | `_shuffle(y, groups, random_state)`: `random_state.permutation(len(y))` over all samples; then `_permutation_test_score` reruns the whole `cv.split` with `estimator.fit` on the shuffled labels (`sk_validation.py` `_shuffle`, `_permutation_test_score`, call in `permutation_test_score`) | all labels permuted at trial level, refit [`trl_rerun`] | 94–99% |
| scikit-learn with `groups=` | `groups` is passed both to the splitter and to `_shuffle` (routing in `permutation_test_score`). `_shuffle` permutes **within each group** (`indices[this_mask] = random_state.permutation(indices[this_mask])`). If groups are the blocks and the label is constant within a block, the shuffled labels equal the observed ones, so every null score equals the observed score and p ≈ 1 (the test cannot pass). Between-block permutation is not offered | none (degenerate) | — |
| MVPA-Light / FieldTrip `ft_statistics_mvpa` | `y_perm = y(randperm(result.n), :); permutation_perf = fun(result.cfg, X, y_perm);`; all labels permuted at trial level, whole analysis rerun (`mvl_stats.m` level-1 permutation) | [`trl_rerun`] | 94–99% |
| CoSMoMVPA `cosmo_randomize_targets` | **From the code body (`cosmo_rand.m` l. 58–93), not the header comment:** if every sample is its own chunk, all labels are permuted; otherwise each chunk must contain every target, else the function **stops with an error** ('chunk %d has missing target'); when chunks contain every target (e.g. chunk = run with both conditions), labels are permuted **within each chunk at sample level**. So a block design with one label per chunk cannot use it; with chunk = run it is a within-run trial-level permutation. The example script reruns `cosmo_crossvalidate` | within-run trial-level, refit [close to `trl_rerun` restricted to runs] | measured in step 2 (`runs_add3/tools/SUMMARY-TOOLS.md`) |
| PyMVPA (tutorial recommendation) | `AttributePermutator('targets', limit={'partitions': 1}, count=1)` permutes the targets of the **training partition only** in each fold, and the tutorial calls whole-dataset permutation "a common mistake" (`pymvpa_tut.rst` l. 256–295) | training labels only, refit [`trn_trl`; block form `trn_blk`] | 75–97% (trial), 68–93% (block) |
| ADAM `cfg.randompermutations` | **From the code, not the help text:** the help text (`adam_first.m` l. 290–292) describes permuting the training labels, but the code permutes all trial labels before the test set is copied and the folds are made (commit 27fefb9e19, `classify_RAW_eeglab_data.m` l. 383–391) | [`trl_rerun`] | 94–99% |

## Notes
- With calibration and held-out trials from separate blocks with independently assigned labels (step 1 `sep24`), the block-level forms were valid (fixed decoder 2.6–5.9%, training-label block form 2.9–4.6%), but the trial-level forms were not: binomial and trial-label permutation 19–30%, training-label trial form 7–14%; under GroupKFold (whole blocks held out) trial-level permutation passed 24.7% (mouse) and 16.3% (EEG). Holding out whole blocks makes block-level permutation valid, not trial-level tests. The large failures come with splits that share blocks, which every surveyed study used (practice survey 14/14).
- No default offers to permute block labels between blocks, training and held-out together, and refit, the scheme that kept 5% with shared blocks in step 1 (`blk_rerun`). In scikit-learn it needs a custom permutation (e.g. permute a per-block label vector and map it to samples) passed through a loop over `cross_val_score`.
- Default splits differ by tool: scikit-learn/MNE `cv=None` unshuffled StratifiedKFold; MNE tutorials `cv=5` or shuffled k-fold; MVPA-Light repeated shuffled k-fold; CoSMoMVPA and PyMVPA tutorials leave-one-chunk-out. Results attributed to a tool must use that tool's split as well as its permutation rule.

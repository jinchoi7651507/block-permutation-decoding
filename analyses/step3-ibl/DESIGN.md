# Step 3: decoding the block side in the IBL brain-wide map with the common tests — design v1 (after two reviews; not stamped)

v0 (commit 3b30fd7) was reviewed by a statistician (`review-statistician.txt`) and a systems neuroscientist who works with these data (`review-ibl.txt`); §12 lists what changed. Written before any IBL spike file, trials table or label is downloaded or opened. Before running: re-review, this design committed and timestamped (OpenTimestamps) and attested, the label-free pilot of §9, the session order and budget timestamped, then the run. Results are reported whatever they show.

## 1. Questions
- **Q1 (false positives on real IBL noise).** When the block side of a session is replaced by an independent draw from the task's own block generator (labels with no information), how often do the common tests call it decodable from a brain region's pre-stimulus activity?
- **Q2 (verdict change on the real labels).** On the real block side, in how many region-sessions does the verdict of the toolbox-default test differ from that of the pseudosession test with the decoder refit in every draw? These are changed verdicts under a simplified binary decoder on a sample of sessions; they are not called false positives and are not comparable with the region maps of the papers.
- **Q3 (explicit unit selection).** In a pipeline that selects units on calibration trials and decodes held-out trials, how far does the pseudosession null fail when the selection is kept fixed instead of repeated in every pseudosession?

The papers (Findling et al. 2025; IBL 2025) decode with pseudosession nulls that refit the decoder, including its L1 selection, in every pseudosession. Nothing here re-tests their results; the question is what common alternatives give on the same recordings.

## 2. Data (pinned by call)
- Sessions: `brainwidemap.bwm_query(freeze='2023_12_bwm_release')` (699 insertions, 459 sessions, 139 mice in that freeze); probes of one session are merged, so the sampling unit is the session (eid). The list is sorted by eid and ordered by `numpy.random.default_rng(20261023).permutation`; this order is timestamped before any file is downloaded.
- Units: `brainwidemap.load_good_units(one, pid, qc=1)` (spike-sorting revision "2024-05-06", fixed inside that function); region = Beryl acronym of the unit's channel; a region-session = all good units of one Beryl region in one session (all probes). Included if at least 10 units (a choice for the k = 20 selector and the selection step, not a requirement; the papers used 5; region-sessions lost by this choice are counted).
- Trials: `brainwidemap.load_trials_and_mask(one, eid, min_rt=0.08, max_rt=2.0, exclude_nochoice=True, exclude_unbiased=True, truncate_to_pass=True)` (the function takes no aggregate tag; it loads the trials revision before 2024-07-10); sessions with fewer than 250 kept trials are skipped (as Findling et al.). Differences from the papers, stated: the public decoding code passes `max_rt=None` while the Methods exclude trials over 2 s (we use 2 s); Findling's main prior analysis keeps the unbiased trials, the BWM binary block decoder drops them (we drop them).
- Activity: spike counts per unit in −600 to −100 ms before stimulus onset.
- Versions recorded: ONE, ibllib, brainwidemap commit, prior-localization commit, SHA-256 of `brainbox/task/closed_loop.py`.
- Disk: good-unit spike files only (29–457 MB per insertion in the Alyx metadata of 4 insertions checked by a reviewer; exact sizes summed from the metadata before download); one session at a time; count matrices kept, spike files deleted after counting.

## 3. Labels
- **Real labels:** block side per kept trial (probabilityLeft 0.8 → 1, 0.2 → 0).
- **Fake labels (Q1):** one pool of 220 pseudosessions per session from `generate_pseudo_session(trials, generate_choices=False)` called on the truncated, unmasked trials table, with `numpy.random.seed([2026, 30, session_index, j])` immediately before call j (the generator uses the global NumPy state and has no seed argument); then the session's own mask is applied and p = 0.5 trials dropped. Draws 0–19 are the fake-label experiments; every pseudosession null (§5) uses the pool. The mask depends on behaviour but not on the fake labels, so under fake labels the reference test is exact by exchangeability; under real labels it is exact only if the real blocks follow the generator (checked, §9).
- session_index = position of the session in the timestamped order. All regions of a session share the session's fake draws.

## 4. Pipelines and statistic
- **Statistic: balanced accuracy** (mean of per-class recall), as the IBL decoders do; class shares differ between sessions and between pseudosessions, and plain accuracy against 0.5 rewards the intercept. One definition per split, used identically in every row and every draw: S-main = mean over the 5 folds of the per-fold balanced accuracy (scikit-learn's `permutation_test_score` with `scoring='balanced_accuracy'`); S-block and the selection pipeline = balanced accuracy of the pooled held-out predictions. A unit test checks that the P2 implementation reproduces `permutation_test_score` exactly at 200 draws.
- **Main decoder:** `StandardScaler → SelectKBest(f_classif, k = min(20, n_units)) → LogisticRegression(C = 1, max_iter 1000, class_weight='balanced')`, refit in every fold and every draw.
- **Splits:** S-main shuffled KFold(5) with seed `[2026, 31, session_index]` (does not depend on labels); S-block GroupKFold(5) by the blocks of the label vector being scored (recomputed for every draw from that draw's own blocks), scored on the pooled held-out predictions (test folds often hold one class).
- **Selection pipeline (Q3; a pipeline of the kind used in the field, not a reproduction of any analysis):** for a label vector, calibration = the first half of each of its blocks (time order), held-out = the second half; units with a two-sample KS test p < 0.05 between the two sides on calibration trials are selected, and if fewer than 2 pass, the 2 units with the smallest KS p (the same rule in every draw, so every region-session has a result); the main decoder (without SelectKBest) is fitted on calibration and scored on held-out trials. The calibration/held-out split is always recomputed from the label vector being scored; SEL-fixed keeps only the selected units (not the split), so its null differs from SEL-repeat in exactly one step, the selection.

## 5. Tests (rows)
| Row | Rule | Status |
|---|---|---|
| P1 | one-sided z test of the pooled held-out balanced accuracy against 0.5, variance (1/n₁ + 1/n₂)/16 from the two class counts (the balanced-accuracy form of the binomial test) | trial independence assumed; also reported minus its own i.i.d. baseline |
| P2 | scikit-learn `permutation_test_score` (all trial labels permuted, CV rerun), statistic balanced accuracy | toolbox default |
| P4 | training labels only permuted per fold, refit, test labels kept (PyMVPA/ADAM rule) | |
| PS-refit | pseudosession null from the pool: labels of pseudosession j, the whole pipeline (folds where label-dependent, selection, fit) rerun | **reference** (the papers' rule) |
| PS-fixed | decoder fitted once on the scored labels; its held-out predictions scored against each pseudosession's labels | invalid by construction; Extended Data (step 1 `blk_fixed` analogue) |
| SEL-repeat | selection pipeline; null = pseudosessions with selection and fit rerun | valid by the same argument as PS-refit |
| SEL-fixed | selection pipeline; null = pseudosessions with the selected units of the scored labels kept, split and fit rerun | the case Q3 measures |
- Null draws: PS rows use 200 pseudosessions of the pool: for fake draw j (j < 20), the first 200 pool members other than j, in pool order; for the real labels, pool members 20–219. P2 and P4 use sequential Monte Carlo p values (Besag–Clifford: stop at h = 10 exceedances, p = h/k at stop after k draws; otherwise the full 200 draws and the usual p; at α = 0.05 the decisions equal those of 200 draws), seeds `[2026, 32, session_index, region_index, label_index, rule_index]`. p = (1 + #{null ≥ observed}) / (n + 1); an undefined observed statistic gives NaN, counted as an error. Monte Carlo uncertainty of p near 0.05 is reported (share of p in 0.03–0.07).
- Not used: P3 (one run per session) and block-label permutation (IBL blocks alternate strictly, so permuting block labels produces sequences the task cannot produce).
- **i.i.d. control (Q3 and baselines):** for each fake draw j (j < 20), labels = a random permutation, at trial level, of draw j's own labels (so the class share is exactly draw j's; seeds `[2026, 33, session_index, j]`), using draw j's calibration/held-out split and folds. Rows: selection pipeline with (a) a trial-permutation null with selection repeated and (b) the same null with the selected units kept (the i.i.d. counterpart of SEL-fixed); main decoder S-main P1, P2, P4 (the share-matched i.i.d. baselines). Needed to attribute any SEL-fixed inflation to the block structure (the selection-interaction claim) and to read P1 and P4 against their baselines.

## 6. Arms
- **Q1 fake labels (20 per session):** main decoder S-main: P1, P2, P4, PS-refit (sanity), PS-fixed; S-block: P2, PS-refit; selection pipeline: SEL-repeat, SEL-fixed; i.i.d. control.
- **Q2 real labels:** main decoder S-main and S-block: P1, P2, P4, PS-refit, PS-fixed; selection pipeline: SEL-repeat, SEL-fixed.
- **Positive control:** stimulus side (right vs left, zero-contrast trials excluded) in 0–100 ms after stimulus onset, main decoder S-main, null = pseudosessions of the pool scored on their stimulus sides (the BWM rule), each draw restricted to the trials kept by the real mask and with non-zero contrast in that pseudosession (as prior-localization does); a pipeline check. Expected: significant in more region-sessions of the regions listed with significant stimulus decoding in the BWM `region_info.csv` than of the other regions (2 × 2 table, plus a row for regions without a value; not a test of the BWM map). The file is read by a script that keeps only the `Beryl` and `stim_dec_sig` columns and drops every other column before anything is printed; its `prior_dec_*` columns (the published prior map) are never read.
- Cut from v0: the continuous-prior (Lasso, R²) arm and region-level Fisher/FDR counts as a main outcome (region counts are given in Extended Data for regions with ≥ 3 sessions, descriptive only).

## 7. Outcomes and primary contrasts (fixed now)
- Unit of aggregation: per mouse, the mean over its region-sessions (for Q1 first the share over the 20 fake draws per region-session), then the mean over mice; 95% intervals by a mouse cluster bootstrap (B = 20,000, seed 20261023, BCa); numbers of mice, sessions and region-sessions reported. "Inflated" = lower bound above 10%.
- **F (Q1):** rate of P2 minus the realised rate of PS-refit, S-main, main decoder, paired at (region-session, draw) (PS-refit is exact by construction, a sanity check).
- **V (Q2):** share of region-sessions significant under P2 minus share under PS-refit on real labels, S-main, main decoder; reported with the 2 × 2 verdict table (both, P2 only, PS-refit only, neither) and the McNemar-type discordant counts. The P2-only region-sessions are cross-tabulated against their own fake-label P2 rate (above vs below 10%).
- **S (Q3):** rate of SEL-fixed minus rate of SEL-repeat on fake labels, all region-sessions, paired at (region-session, draw); beside it the same contrast in the i.i.d. control.
- A test rejects when p < 0.05 (strict), in every row (this keeps the sequential P2/P4 decisions equal to those of 200 draws).
- Decision: a contrast is called positive if the lower bound of its 95% BCa interval is above 0. Rates are also reported weighted by region-session (all region-sessions equal).
- Multiplicity: three primary contrasts, each with its 95% interval and a Bonferroni 98.3% interval; no conclusion rests on a single interval. NaN/errors excluded per cell with denominators reported.
- Secondary: P1, P4, PS-fixed minus PS-refit; S-block; positive control; Extended Data region counts.

## 8. Predictions (fixed before running; may be wrong)
- Q1: P1, P2, P4 under S-main above 10%; PS-refit about 5% (sanity); PS-fixed above PS-refit; S-block P2 lower than S-main P2. The likely source is slow block-scale structure in the recordings (drift, or block-related signal leaking through the trial-level shuffle), not drift alone.
- Q2: more region-sessions significant under P2 than under PS-refit; P2-only region-sessions have higher fake-label P2 rates than the others.
- Q3: SEL-fixed above SEL-repeat on fake labels, and near SEL-repeat in the i.i.d. control.

## 9. Pilot, realism check and budget (label-free, before the run)
- **Realism check (labels only, no spikes):** trials tables of the first 30 sessions of the order: block lengths (the censored last block of each session left out), number of blocks and class share of the real sessions against 220 pseudosessions per session, strict side alternation asserted; KS distances with ties reported with a permutation p (block lengths are integers). The first 90 trials have probabilityLeft 0.5 (asserted); a session where this fails is excluded and listed. Pre-set response: if the real block-length distribution differs from the generator's (two-sample KS p < 0.01 pooled), PS-refit on real labels is reported as approximate and Q2 is reported as descriptive only; Q1 is unaffected (fake labels come from the generator).
- **Timing pilot:** 2 sessions from the start of the order, all rows, p values computed and discarded unread; time per region-session t_rs.
- **Budget (fixed formula):** number of sessions = floor(C / (t_rs × r)), C = 150 core-hours (the laptop at the throttled speed measured in step 2, after the step 2 runs end), r = mean number of included region-sessions per session from the clusters metadata of the first 60 sessions (unit counts only). The budget outcome (t_rs, r, number of sessions) and the list of regions marked stimulus-significant in `region_info.csv` (the two-column extract) are logged and timestamped with the session order before the run. No result file is opened during the run, and arms are cut for compute only, never after looking at results. Minimum target: 30 mice; if the budget gives fewer, the author decides before the run whether to extend C or report Q1–Q3 as a pilot-size study. Stop rule: the analysis uses the completed prefix of the timestamped order. Cut order if compute runs short: S-block, then the real-label PS-fixed, then the positive control; Q1 S-main, Q2 S-main and Q3 are never cut. Disk under 60 GB at any time.

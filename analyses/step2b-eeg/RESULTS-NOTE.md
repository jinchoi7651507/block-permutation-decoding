- **Reading (pre-specified as "a finding, reported", DESIGN §7).** P5's exactness comes from random assignment. For a fixed order it holds only if the block-level data are exchangeable under the null, which these recordings violate for trend-correlated patterns: P5 rejects in 94.7% of subjects for first half vs second half (correlation of the labels with block index about 0.87), 28.9% for AABB (about 0.43) and 2.6% for ABBA (0), and under S-block 100% and 63.2% (so "S-block: P5 exact" holds only for random assignments). P5 is not malfunctioning here: it detects a real confound, label = time. Candidate sources, not separated by this design: vigilance, electrode or impedance drift; a state × time interaction (for example drowsiness building mainly in eyes-closed blocks), which a 4 + 4 state balance per class does not cancel; and the fact that all 38 subjects start with eyes closed (QC-NOTE: EC-first 40/40), so each pattern has the same state–time layout in every subject and common time effects add up across subjects. Separately, a design property: each S-block test fold holds one state (addendum 1 §4), so under S-block a state × time drift is tested within one state. Three patterns cannot tell a linear drift from other slow structure; ABBA is orthogonal to a linear trend but not to a quadratic one (|r| 0.21 with the squared centred block index). ABBA's near-5% rate is "not contradicted, at low resolution" (38 tests; under S-block 34% of its P5 p values are below 0.20).

## 3. Group level (balanced, S-main)
Over the 50 assignment indices, the one-sided t-test of per-subject accuracy against 0.5 rejected in **100%** (bootstrap interval 100–100%); the Stelzer-style group null in **4%** (2 of 50 indices; the indices are correlated because they share subjects). The group null uses 2,000 draws (addendum 1 §6; DESIGN §6 had said 10,000). **The script's bootstrap interval for the group-null share (6–24%) is computed as specified but is not a valid interval for that share and is not interpreted:** in each resample a subject drawn twice contributes its observed accuracy twice, while `group_tests` draws an independent null accuracy for each copy (`rng.integers(0, D, (n_null, S))`), so the null mean has about half the variance of the observed mean (standard deviation about √2 smaller under typical multiplicities) and the test is too liberal inside every resample (an approximate calculation gives about 12% rejection under the null, consistent with the interval). The fewer group-null draws per resample (500) contribute little. The same bias affects the t-test interval, harmlessly at ceiling. The script is stamped and unchanged; any repair (one null draw per unique subject, weighted by multiplicity) would be a separate, labelled post hoc computation (not done).

## 6. Alpha-power slope over the 16 min (DESIGN §6 E6) — definition written 23:50 KST before computing; SPECIFIED AT RESULTS TIME
DESIGN §6 (E6) pre-specified the item ("correlation of the fake labels ... with the alpha-power slope over the 16 min, logged; inflation reported against them"; addendum 1 §6: "computed from the features in the results note") but never fixed its estimator. It is fixed here, before computing, by author decision 2026-10-26 23:48, and labelled "specified at results time".
- **Per subject (38, cleaned_s5, all kept epochs before the equal-count subsampling):** posterior log alpha = mean over the 11 posterior channels of `preprocess.py` POSTERIOR (O1, Oz, O2, PO3, POz, PO4, PO7, PO8, P3, Pz, P4) of the 8–13 Hz log band-power feature, as in the QC alpha check. Time of an epoch = its block index (0–15) plus (rank within the block + 0.5) / epochs in that block, in block units (one block about 60 s); the feature files store no epoch time, and epochs are in recording order within each block.
- **Slope:** ordinary least squares of posterior log alpha on time with eyes-closed/open as a covariate (so the 60-s state alternation does not enter the slope), in log-alpha units per block. Also reported: the slope within eyes-closed epochs only and within eyes-open epochs only.
- **Inflation against it (primary of this item):** Spearman correlation across subjects between |slope| and the subject's P2 rejection rate (balanced arm, S-main, main readout, cleaned_s5, 50 assignments). **Secondary (descriptive):** Spearman between |slope| and each subject's fixed_half P5 p value under S-main; and the per-subject mean |label_block_corr| as stored.
- Reported: the distribution of slopes (median, range, share negative), both correlations with a subject-bootstrap 95% interval (B 20,000, seed 20261026). No threshold, no verdict; descriptive.
- **Result** (`code/posthoc_alpha_slope.py` after review, ready with no MUST; output `results/alpha_slope.json`; descriptive): slope with the state covariate, median +0.0045 log-alpha units per block (range −0.059 to +0.084; 14 of 38 negative); within eyes closed median −0.0016, within eyes open +0.0101. Spearman between |slope| and the subject's P2 rejection rate: **0.10 (95% subject bootstrap −0.23 to 0.41)**; between |slope| and the fixed_half P5 p value: −0.07 (−0.39 to 0.26); all 20,000 bootstrap draws valid in both. No association is visible in this descriptive check: the linear posterior-alpha slope does not track which subjects inflate.
- **Limits (review):** P2 rates are near ceiling (about 92%), so an across-subject correlation has little room; |slope| is not scaled by each subject's residual variability; a linear slope misses non-monotone drift; posterior alpha is one of 305 features, a proxy for the drift the classifier uses; rank-based time ignores rejected windows (shift under one block). A within-subject version (across the 50 assignments, P2 rejection against the labels' correlation with state-adjusted block-mean alpha) is closer to E6's wording but was not in the definition; not run.

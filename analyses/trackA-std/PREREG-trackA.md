## 3. Common definitions
- **Trials:** drifting gratings, **drifting direction 0° against 90°** (Allen's `orientation` column; the two differ in both direction and orientation), all five temporal frequencies pooled (as in the original run), response window 0–2 s, calibration = first half of these trials in time order, held-out = second half. Invalid times are **not** excluded (as in the planned script); overlaps are counted and reported.
- **Always guessing:** the held-out majority class (an oracle rate; conservative for any decoder).
- **Recorded area:** one (session, visual area) pair with ≥ 20 units after the unit filter and the 0.5 Hz rate rule (rate computed on the trials of that analysis). In code and tables this is called an area unit.
- **Unit filter:** Allen `quality == "good"` for every analysis. Sensitivity (P1 only): every sorted cluster, and the AllenSDK default filter (good, isi_violations < 0.5, amplitude_cutoff < 0.1, presence_ratio > 0.9). Units with presence_ratio < 0.9 are counted per area and reported.
- **Areas:** primary VISp, VISl, VISal, VISrl, VISam, VISpm. Sensitivity: every acronym starting with "VIS".

## 4. Analyses
**P1 (primary; the planned readout).** `ephys-matched-null.py` unchanged, run once over all 32 sessions in index order with `--seed 1 --good-only --dump-draws` (one run, because its random generator is shared across sessions). Per recorded area: free = best-split held-out accuracy; null = mean of 200 random-ordering draws with the same cut search; const = always guessing. g_null = free − null; d = null − const; g_const = free − const; p_spec = (1 + #{draw ≥ free}) / 201 (descriptive; exact only under no information). Sensitivity runs: the same command without `--good-only`, and with `--sdk-qc`.

**P2 (co-primary; standard decoder).** Units ranked by |d′|; L2 logistic regression (penalty 0.5·‖w‖², intercept unpenalised, z-scored counts) (counts z-scored with the mean and s.d. of all calibration trials; label-free, the same in the null) on the top k units, k ∈ {5, 10, 20, 40} (≤ number of units) chosen by 5-fold cross-validation inside calibration (folds = calibration position mod 5) **with the ranking recomputed on each training fold**; ties to the smaller k; final ranking and fit on all calibration trials; held-out accuracy. Specificity null: the identical procedure with the ranking replaced by a random unit order, 200 draws. Δ2 = held-out accuracy − null mean. Chosen k (observed and null) and non-converged fits are reported.

**P3 (information null for the planned readout; descriptive).** Labels shuffled within strata of (half × temporal frequency × Allen stimulus block), where presentation order is randomised; the full selection rerun; 200 shuffles. Excess = free − shuffle mean; p = (1 + #{shuffle ≥ free}) / 201. Expected to reject in nearly every recorded area (gratings in visual cortex).

**C (calibration on spontaneous activity; measurement, no verdict).** The three longest spontaneous epochs, each ≥ 240 s (otherwise C is skipped for that session and reported), lose their first 1 s and are cut into 4 equal blocks each: 12 blocks of about 74 s, none spanning a gap between epochs. Non-overlapping 2-s pseudo-trials tile each block. Same unit filter and ≥ 20 units. Fake labels and splits:
- **iid:** labels random per pseudo-trial; odd pseudo-trials select, even ones validate.
- **segment:** blocks 1–6 one label, 7–12 the other (one stretch of time per label); odd/even split.
- **random blocks:** blocks 1, 2, 5, 6, 9, 10 select and blocks 3, 4, 7, 8, 11, 12 validate; the labels are assigned to blocks at random, 3 of 6 per label in each set (one of the 400 assignments, drawn with the area's random stream), so the block shuffle is exact by randomisation.
Tests (α = 0.05; every null reruns the selection): **Q2**, held-out correct count against always guessing, one-sided binomial; **trial shuffle** (iid, segment), labels permuted across pseudo-trials, 200 draws; **block shuffle** (segment: all C(12,6) = 924 assignments of the labels to blocks; random blocks: all C(6,3)² = 400 assignments within the selection blocks and within the validation blocks; p = proportion of assignments scoring ≥ the observed one, observed included); **specificity**, 200 random orderings.
Null draws that are NaN count as reaching the observed score (conservative) and are reported.
Expectations written before data (from simulations on constructed data): iid, all tests near or below 5%. Segment: Q2, trial shuffle, block shuffle and specificity above 5% to the extent of slow trends or autocorrelation across blocks (the segment block shuffle relies on exchangeable blocks, which a trend violates; no shuffle can correct one stretch of time per label). Random blocks: block shuffle at or below 5% (exact by randomisation); Q2 can exceed 5%, because errors within a held-out block are correlated (the binomial treats pseudo-trials as independent) and a block-scale state can align with a label by chance; specificity near 5%.

**Random streams.** P1 as in the planned script (seed 1). P2, P3, C: `numpy.random.default_rng([20261014, session, crc32(area), stream])`, independent of session order and of how the work is split. Bootstrap: `default_rng(20261015)`; verdicts use this seed only; seeds 1–4 show Monte Carlo spread.

## 5. Estimands and decision rules
- **Animal level:** per mouse, the unweighted mean over its included recorded areas; then the unweighted mean over mice. 95% percentile interval from a cluster bootstrap over mice, B = 20,000 (the same resample indices for estimands that share the same set of mice). Mice without an included recorded area are excluded; included and total mice are reported, and [n] in section 7 is the number included.
- **Co-primary, each with its own unadjusted 95% interval; no claim of the form "any of" is made:** (a) g_null, new set, good, six areas: **replicated** if the lower bound > 0. (b) d, same cell: positive if the lower bound > 0. (c) Δ2, same cell: above zero if the lower bound > 0.
- **Ratio** R = mean d / mean g_const (ratio of means), interval over resamples with a positive denominator (the number of other resamples reported). Sentence M3 branch: **share** ("a quarter", "a third" or "half") if the d and g_const lower bounds are > 0, no resample has a non-positive denominator, and exactly one of 1/4, 1/3, 1/2 lies in the R interval; **ratio** (R to two decimals) if the same first three conditions hold but not exactly one share lies in the interval; **d** otherwise. The summary script prints the branch (`m3_branch`).
- **Proportions** (P2 p < 0.05, P3 p < 0.05, every C cell): per mouse the proportion of its recorded areas, then the mean over mice, with the cluster interval.
- **Reported, no verdict, not in the abstract:** every sensitivity cell (unit filter × set × area set), the original set alone and the 32 mice combined, P2/P3/C in the original set, genotype (wild type vs Cre, descriptive), chosen k, invalid-time overlaps, running speed per half and per spontaneous block, presence-ratio counts.
- **Expected with near certainty in visual cortex:** d > 0 and P3 rejection. The informative quantities are g_null, R, Δ2 and C.

## 6. Gates and failure handling
- **Gate 0 (before any new session is downloaded):** download the two original sessions only (`download_sessions.py --only original`), check their SHA-256 against section 2, run the planned script on them with `--good-only` and without it, and compare with `expected/`. A mismatch here may be fixed by changing the software environment only (no data of a new session has been seen); record what was changed.
- **Gate 1:** `smoke_test.sh` ends with "smoke test OK".
- **Gate 2:** in the full runs the original rows must equal `expected/` exactly; `trackA_summarize.py` enforces this and computes nothing if it fails.
- **Gate 3:** every file matches the server size and `MANIFEST.sha256` is written.
- **Unreadable or failed session:** reported with the reason; it is removed from the session list and all three P1 runs are repeated (the shared generator changes the null draws of later sessions; disclosed).
- **Crash of new code on real data:** a fix that only stops the crash, made before any output of that run is viewed, is allowed; the diff and reason are recorded. Any change to computations after outputs are viewed is a deviation reported as such.
- **Workers:** each worker log must end with a DONE line for each of its sessions; the summary checks that every session has rows and that P1 and P3 agree on the observed score.
- **Summary checks:** the summary script stops without estimates if a session is missing (other than those removed under this section and passed with `--excluded`) or P1 and P3 disagree on any observed score.
- **Gate failure** (0 or 2): stop; the frozen v108.2 abstract is submitted unchanged and Track A is reported in the manuscript.
